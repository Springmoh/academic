st0=>start: start Start ROS2 robotic arm system
op1=>operation: Initialize ROS2 nodes, YOLO model, camera, publishers, subscribers, QoS
cond2=>condition: Input source?
op3=>operation: Manual input: user adjusts x_t, y_t, z_t using slider GUI
op4=>operation: Publish target point to ROS2 topic
op18=>operation: Arm calculation node receives target point
cond19=>condition: x_t > 0?
op20=>operation: Reject target: x_t must be greater than 0
op28=>operation: Loop while ROS2 is running
op5=>operation: Read camera frame
cond6=>condition: Frame captured successfully?
e29=>end: end End / shutdown ROS2 nodes
op7=>operation: Run YOLO tracking on frame
cond8=>condition: Object detected with tracking ID?
op9=>operation: No detection: publish default/home target and set z flag = 1
op17=>operation: Publish target coordinate, cut data, object count, and display annotated frame
op10=>operation: For each detected box: calculate center, area, confidence, and track ID
cond11=>condition: Current target track ID found?
cond15=>condition: Target lost longer than timeout?
op16=>operation: Re-track target using nearest object or previous bounding region
cond12=>condition: Target center inside tolerance area?
op13=>operation: Publish home/center target coordinate
op14=>operation: Publish detected target center coordinate
op21=>operation: Calculate l, h, and phi from target x_t, y_t, z_t
cond22=>condition: h <= 2 * arm_length?
op23=>operation: Reject target: point is outside reachable workspace
op24=>operation: Calculate theta, base angle a_b, elbow angle a_e, wrist angle a_w
cond25=>condition: First run?
op26=>operation: Save initial angle offsets as home calibration
op27=>operation: Publish joint_angles in radians and stm32_angles in degrees
